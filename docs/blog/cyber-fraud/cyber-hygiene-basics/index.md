# Cyber Hygiene Basics: Everyday Habits That Reduce Digital Risk

Cyber hygiene is the set of routine practices that help keep devices, accounts and information safer. It cannot eliminate every threat, but consistent habits reduce common opportunities for fraud and compromise.

## 1. Protect accounts

Use a unique password for every important service. A reputable password manager can help create and store strong passwords. Enable multi-factor authentication, prioritising phishing-resistant methods where available.

## 2. Keep software updated

Install operating-system, browser, application and router updates from trusted sources. Updates often include security fixes. Replace devices and software that no longer receive security support when practical.

## 3. Be careful with messages

Treat unexpected links, attachments, QR codes and payment requests cautiously. Verify sensitive requests through a separate channel. Do not share OTPs, passwords or recovery codes with callers or message senders.

## 4. Secure devices

Use a screen lock, device encryption and automatic updates. Install applications from trusted sources and review app permissions. Remove software you no longer need.

## 5. Protect your network

Change default router credentials, use modern Wi-Fi security, update router firmware and disable remote administration if it is not needed. Avoid sensitive activity on untrusted devices.

## 6. Back up important data

Maintain backups protected from accidental deletion and ransomware. Test restoration periodically; a backup that cannot be restored is not a reliable recovery plan.

## 7. Review account activity

Turn on security alerts where appropriate. Review active sessions, recovery methods, payment beneficiaries and recent transactions. Report unexpected changes quickly.

## A simple monthly check

- Review critical account recovery settings.
- Check for unfamiliar devices and active sessions.
- Update devices and applications.
- Remove unused apps and browser extensions.
- Confirm backups are current and restorable.
- Review bank and payment notifications.

## Key takeaways

Cyber hygiene is not a one-time setup. It is a routine: unique passwords, strong authentication, updates, cautious communication, secure devices and recoverable backups.
