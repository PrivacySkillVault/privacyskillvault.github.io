# D03 — Offensive Security & Testing

Understand common attack paths so weaknesses can be identified, validated, explained, and remediated in authorised environments.

## Learning areas

- Scope, rules of engagement, asset discovery, and safe test planning
- Reconnaissance and service enumeration
- Web application fundamentals and common vulnerability classes
- Authentication, session management, access control, and input handling
- Vulnerability validation, evidence capture, impact assessment, and remediation
- Retesting and clear technical reporting

## Practical exercise

Use an intentionally vulnerable local application. Define the scope, identify one low-risk finding, reproduce it without accessing real user data, capture minimal evidence, explain impact, recommend a fix, and retest.

Only test systems you own or have explicit written permission to assess. Avoid destructive payloads, production data, persistence, or unnecessary service disruption.
