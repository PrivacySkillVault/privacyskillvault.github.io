# D04 — Security Operations & Investigations

Develop a repeatable approach to investigating suspicious activity using evidence from endpoint, network, identity, application, and fraud-monitoring systems.

## Learning areas

- Alert validation, triage, prioritisation, and escalation
- Timeline construction and event correlation
- Endpoint process, persistence, and authentication analysis
- Network and DNS investigation
- Threat intelligence: relevance, confidence, age, and context
- Cyber-fraud patterns, account takeover signals, and transaction context
- Incident handling, evidence integrity, containment considerations, and lessons learned

## Practical exercise

Use a synthetic alert dataset. Define the question, preserve original evidence, normalise timestamps, correlate related events, identify what is known and unknown, and write a conclusion with confidence and next steps.

Separate observed facts from assumptions. Record data-source limitations, time-zone handling, missing telemetry, alternative explanations, and confidence.
