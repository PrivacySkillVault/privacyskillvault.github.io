# Learn

A structured learning map for the technical foundations and security workflows covered by Privacy Skill Vault.

The curriculum is organised into five connected domains. Each domain will grow through concise explanations, tested examples, exercises, and references. A topic is not described as lab-tested until it has actually been validated.

## How to use the learning paths

1. Start with the domain overview and prerequisites.
2. Work through concepts before attempting the practical exercise.
3. Record commands, versions, expected output, and observed results.
4. Link the exercise to a lab or investigation where relevant.
5. Revisit the references and note limitations or environment-specific behaviour.
