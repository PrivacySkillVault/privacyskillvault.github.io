# D05 — Operations, Maintenance & Capstone

Connect technical security work to stable, supportable operations.

## Learning areas

- Service health, capacity, storage, performance, and availability
- Patch, configuration, and vulnerability management
- Backup, recovery, disaster recovery, and change control
- Automation with reviewable scripts and safe failure handling
- Operational documentation, runbooks, escalation, and handover
- Detection and platform maintenance, tuning, and regression testing

## Capstone approach

Choose a small, authorised lab environment and define a measurable security objective. Build the environment, generate test activity, collect telemetry, implement a detection, investigate the result, tune false positives, document operational requirements, and demonstrate recovery or rollback.

## Completion evidence

Scope, architecture, assumptions, reproducible setup and version details, test cases and observed results, security and operational risks, recovery procedure, and lessons learned.
