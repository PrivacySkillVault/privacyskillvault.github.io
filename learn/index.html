Learn¶

A structured learning map for infrastructure, monitoring, detection engineering, application security, investigations, and reliable security operations.

The curriculum uses recognised standards and primary technical specifications where they apply. The Industry Standards & Authoritative References page records the publisher, version, scope, and limitations of each source.

D01Infrastructure & Platform FoundationNetworking, operating systems, virtualisation, cloud, telemetry foundations, and platform operations. D02Security Monitoring & DetectionTelemetry engineering, SIEM data quality, Sigma, ATT&CK, detection testing, and alert operations. D03Offensive Security & TestingAuthorised testing, OWASP ASVS verification, vulnerability validation, CVSS, and reporting. D04Security Operations & InvestigationsNIST incident response, evidence provenance, account takeover investigation, and SAMA counter-fraud references. D05Operations, Maintenance & CapstoneChange, service health, vulnerability management, recovery, automation, and operational evidence.

How to use the learning paths¶

  1. Start with the relevant domain and authoritative source.
  2. Check the version, scope, and applicability before using a requirement.
  3. Separate the source requirement from the implementation example.
  4. Work through the practical exercise in an authorised environment.
  5. Record versions, commands, expected results, raw evidence, and observed results.
  6. Link the exercise to a lab or investigation where relevant.
  7. Record limitations and the date the material was last reviewed.

Evidence labels¶

  • Standard / framework reference: a direct reference to a published source.
  • Implementation guidance: a practical interpretation, not a verbatim requirement.
  • Lab-tested: executed in a controlled environment with evidence recorded.
  • Simulated scenario: synthetic material for learning.
  • Research note: reviewed against documentation but not independently executed.

Unfinished work will not be presented as complete. A control mapping is not proof of compliance, and a sample exercise is not a formal assessment.
