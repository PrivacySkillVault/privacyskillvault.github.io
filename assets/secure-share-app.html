Secure Share

A separate, temporary browser-to-browser transfer tool for confidential notes and small evidence files. Content is encrypted in the sender's browser before transfer.

This is not the passphrase-based Secure Evidence Share utility. That existing encrypt/decrypt tool remains unchanged.

Create a one-time transfer

Select either a text note or up to 20 files. Multiple files are packaged into one ZIP archive. Keep this page open until the recipient completes the download. Maximum total payload: 100 MB.

Approve only a recipient you have independently verified. Anyone who obtains the full link may attempt to connect.

Request access from the sender. The sender must approve before encrypted data is sent.

Security model and limitations

  • Payload encryption: AES-256-GCM with a fresh random key and nonce for each transfer.
  • Payload travels through a WebRTC data channel; the PSV website does not receive or store the plaintext or ciphertext payload.
  • The decryption key is carried in the URL fragment. The complete link is a bearer secret; share it only through a trusted channel.
  • PeerJS 1.5.5 is pinned to a fixed CDN version and provides signalling only. The signalling provider can observe connection metadata.
  • Direct peer connectivity can fail behind restrictive NATs or firewalls. This release does not provide a TURN relay or offline delivery.
  • The sender must remain online. The session expires after 10 minutes and accepts only one approved recipient.
  • Once decrypted, the recipient can copy or redistribute the file. This tool cannot enforce downstream handling.
